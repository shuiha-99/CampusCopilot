# Memory v1 冻结开发/回归样例

这是一条24消息的固定样例。`manifest.json` 锁定消息和已记录的真实 Ollama 摘要；回归脚本用当前上下文构造代码重放摘要，检查输入内容字符数及关键未知状态。更改输入或记录摘要须发布新版本，不覆盖本版。

在项目目录运行 `python -m scripts.check_memory_frozen_regression`。它无需启动模型或数据库；首次真实 Ollama 摘要及 MySQL/HTTP 验证仍见原始报告与对应专项脚本。

此样例曾参与摘要提示词调整，属于冻结开发/回归样例，并非独立测试集。16.12%是这一条样例的模型消息**内容字符数**减少，不是 Token、费用或总体平均。记录摘要保留了“2026年截止日需查”和“旧金额不能直接作为目标年度标准”，但没有逐年分开列明2024/2025资助档次；脚本会显式报告这一项未通过。
